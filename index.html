FAQ

자주 묻는 질문

첫봄의 AI 돌사진 생성 방식과 데모 이용 조건을 확인해 보세요.

AI로 아기 돌사진을 어떻게 만드나요?

아기 얼굴이 잘 보이는 사진을 최대 3장 올리고, 원하는 의상·배경·분위기를 적어 생성 요청을 보내세요. 생성 결과는 이 브라우저의 사진 보관함에 저장됩니다.

사진 생성에 실제 결제가 필요한가요?

아니요. 현재 결제 화면은 테스트 전용이며 실제 청구는 없습니다. 다만 AI 사진 생성을 요청하면 운영자의 OpenAI API 계정에 사용료가 발생할 수 있습니다.

업로드한 아기 사진은 어디로 전송되나요?

사진 생성에 동의하면 선택한 사진과 설명이 OpenAI 이미지 API로 전송됩니다. 생성 결과와 보관 사진은 현재 브라우저에 저장되며, 서버에 보관하지 않습니다.

홈페이지에서 바로 AI 사진을 만들 수 있나요?

현재 공개 홈페이지는 정적 미리보기라 AI 생성 API가 포함되어 있지 않습니다. 생성 데모를 실행하려면 README 안내에 따라 Node 서버와 OpenAI API 키를 설정해야 합니다.
